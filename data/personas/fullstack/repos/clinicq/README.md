# clinicq

Clinic appointment booking platform. Built 2023. (Synthetic portfolio repository.)

## Architecture
Built online booking with reminders, waitlists and a front-desk view.

## Tech
- React
- Node.js
- Express
- PostgreSQL
- Twilio
- Redis

## Layout
- `src/index.js`
- `notify.py`
- `cache.py`
- `db.py`

## Running
```bash
cp .env.example .env
make run
```
