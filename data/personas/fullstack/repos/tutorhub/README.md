# tutorhub

Course platform for a tutoring academy. Built 2022. (Synthetic portfolio repository.)

## Architecture
Built courses, video lessons, quizzes and certificates with background video processing.

## Tech
- Django
- Python
- PostgreSQL
- JavaScript
- Celery
- Redis
- AWS S3

## Layout
- `main.py`
- `tasks.py`
- `cache.py`
- `storage.py`
- `db.py`

## Running
```bash
cp .env.example .env
make run
```
