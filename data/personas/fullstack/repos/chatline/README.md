# chatline

Real-time support chat widget. Built 2023. (Synthetic portfolio repository.)

## Architecture
Built an embeddable chat widget with agent routing, typing indicators and history.

## Tech
- Node.js
- Socket.IO
- React
- MongoDB
- Redis Pub/Sub

## Layout
- `src/index.js`
- `server/pubsub.js`

## Running
```bash
cp .env.example .env
make run
```
