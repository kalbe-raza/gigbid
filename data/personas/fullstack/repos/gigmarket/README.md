# gigmarket

Two-sided freelance marketplace MVP. Built 2022. (Synthetic portfolio repository.)

## Architecture
Shipped profiles, job posts, escrow-style payments and reviews in eight weeks.

## Tech
- MERN Stack
- MongoDB
- Express
- React
- Node.js
- Stripe Connect
- JWT

## Layout
- `src/index.js`
- `server/payouts.js`
- `server/auth.js`

## Running
```bash
cp .env.example .env
make run
```
