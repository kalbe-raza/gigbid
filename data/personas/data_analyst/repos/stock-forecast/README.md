# stock-forecast

Inventory demand forecast. Built 2023. (Synthetic portfolio repository.)

## Architecture
Forecast weekly demand with seasonal models and fed reorder points back to Excel.

- Time Series Forecasting
- Microsoft Excel
- Python
- Forecasting
- statsmodels

## Layout

- `analysis/model.py`

```bash
cp .env.example .env
make run
```
