# meetmate

Multi-agent meeting scheduler. Built 2025. (Synthetic portfolio repository.)

## Architecture
Built a graph of agents that read requests, check calendars and propose slots for human approval.

## Tech
- LangGraph
- Large Language Models
- Python
- AI Agents
- PostgreSQL
- Google Calendar API

## Layout
- `main.py`
- `db.py`
- `calendar_tools.py`

## Running
```bash
cp .env.example .env
make run
```
