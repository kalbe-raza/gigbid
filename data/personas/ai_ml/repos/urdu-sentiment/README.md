# urdu-sentiment

Urdu and English review sentiment classifier. Built 2022. (Synthetic portfolio repository.)

## Architecture
Fine-tuned a multilingual transformer on 18k hand-checked reviews with code-switching augmentation.

## Tech
- Natural Language Processing
- Hugging Face
- Transformers
- PyTorch
- Weights & Biases

## Layout
- `main.py`
- `train_logging.py`

## Running
```bash
cp .env.example .env
make run
```
